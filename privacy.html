Replyra Privacy Policy — Draft for Review

Last updated: November 11, 2026. This is a draft. Confirm all practices, service providers and retention periods before publishing.

1. What Replyra does

Replyra is a Chrome extension that helps you draft customer messages and rewrite product listing text. You choose what to enter, generate and copy. Replyra does not send messages to customers automatically.

2. Data stored on your device

Extension settings, selected AI model, brand voice profiles, saved drafts, local usage counters and a pseudonymous extension/device identifier may be stored in Chrome extension local storage. Saved drafts are enabled by default and can contain generated text; you can disable local saving or delete drafts. The Groq API key you enter is stored locally for later requests. License state is also stored locally.

3. AI requests to Groq

In the currently supported direct BYOK mode, the extension sends your Groq API key and information you submit for generation directly to Groq over HTTPS. This may include customer message text, order context, product listing text and brand voice instructions. Groq processes those requests according to its own service terms and privacy practices. Avoid submitting unnecessary personal information about customers.

4. Subscription verification

When you activate or revalidate a paid license, the extension sends the membership/license key and pseudonymous device identifier to Replyra's Cloudflare Worker. The Worker contacts Whop to check membership status and product eligibility; Cloudflare D1 may store an association between an active membership and the identifier. This is not a physical hardware identifier and is not cryptographic device attestation.

5. How data is used

Data is used to provide writing features, retain user-selected settings and drafts, verify paid access, troubleshoot technical problems and protect service operation. No sale of user data is intended. Confirm logs, telemetry and Cloudflare retention settings before finalizing this statement.

6. Control and deletion

You can stop saving drafts, delete saved drafts, export applicable local content without API keys or license secrets, and delete locally stored data using the Options screen. Full device-identity deletion may prevent reactivation on an already bound paid license; contact support before doing so. Deleting local data does not automatically remove data already processed by Groq, Whop or Cloudflare.

7. Automated suggestions and marketplace policies

AI outputs and Policy Guard warnings are suggestions, not guarantees of factual correctness, legal compliance or Amazon-policy compliance. You are responsible for reviewing every response and listing before use. Replyra is not affiliated with Amazon.

8. Security

Data transmitted to the APIs listed above is sent using HTTPS. API keys remain accessible to the signed-in user's extension environment and cannot be hidden from the device owner. No browser extension can guarantee absolute protection against a compromised device or a modified local copy.

9. Third parties

Depending on usage, Groq processes AI requests, Whop processes membership status, and Cloudflare hosts licensing services and database records. Review their current terms for details about retention, subprocessors and international data handling.

10. Changes

If an optional BYOK generation gateway is introduced in the future, it would route a user's Groq key and text through Cloudflare before Groq. This is not enabled by the current publicly deployed direct mode and will require an updated notice and explicit consent prior to activation.
